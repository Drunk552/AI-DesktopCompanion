## 当前结构说明

### 1. 已删除的旧空目录

以下历史目录已经不再使用，并已从工程中删除：

- `ai_pet/ai/`
- `ai_pet/config/`
- `ai_pet/logger/`
- `ai_pet/memory/`
- `ai_pet/vision/`
- `ai_pet/controller/`

这些目录原本属于旧阶段命名，当前功能已经分别迁移到：

- `intelligence/`
- `shared/config/`
- `shared/logger/`
- `intelligence/memory/`
- `perception/`
- `app/` 与 `brain/`

### 2. 当前架构主线

当前工程已经基本形成以下结构：

```text
main
  -> app/application
       -> mode_runner_*
       -> app_event_bus
       -> module_registry
       -> brain/brain_controller
       -> action/action_coordinator
       -> ui/*
```

其中核心职责分工为：

- `app/`：运行时组织、模式入口、上下文装配
- `brain/`：系统编排、状态更新、事件决策
- `action/`：把 Brain 决策翻译成 UI/行为输出
- `perception/`：摄像头、人脸、情绪识别
- `intelligence/`：LLM、Prompt、Persona、Memory、关系计算
- `shared/`：配置与日志
- `ui/`：界面渲染、页面模块、覆盖层展示

### 3. 当前工程状态

当前代码结构已经不再处于“纯目录迁移阶段”，而是已经进入：

- Brain 中枢已落地
- mode runner 已拆分
- typed event 已逐步引入
- UI 多个模块开始直接消费结构化状态

因此，后续目录文档应以“当前真实落地结构”为准，而不是继续保留旧阶段目录名。
